# 💙 Portfólio | Heloá Vitória

Bem-vindo ao meu portfólio pessoal! ✨

Este projeto foi desenvolvido para apresentar um pouco sobre mim, minha formação, meus interesses e alguns dos meus projetos na área de tecnologia.

## 🌐 Sobre o projeto

O portfólio foi criado utilizando **HTML e CSS**, com uma proposta visual moderna, delicada e responsiva.

A página apresenta:

- 🏠 Página inicial
- 👩‍💻 Sobre mim
- 🎓 Formação acadêmica
- 💡 Interesses
- 💻 Projetos
- 📩 Área de contato

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Design responsivo

## 🎨 Características

- Layout responsivo para computador e celular
- Navegação por seções
- Uso de cores em tons de azul
- Tipografia personalizada
- Seção de apresentação com foto
- Cards para formação, interesses e projetos
